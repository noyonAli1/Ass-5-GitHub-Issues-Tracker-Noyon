1--What is the difference between var, let, and const?
=> var is the old way of declaring variables in JavaScript. A variable declared with var can be declared again with the same name. It is not commonly used in modern JavaScript.
 let is used in modern JavaScript. The value of a variable declared with let can be changed later. It is used when the value may change in the future.
const is used to declare a variable whose value cannot be changed after it is assigned. It is generally used for fixed values.

2--What is the spread operator (...)?
=>In JavaScript, the spread operator (...) is used to expand or spread the elements of an array or object. It allows us to copy elements from one array to another or combine multiple arrays and objects together. It also makes the code shorter and easier to read.

3--What is the difference between map(), filter(), and forEach()?
=>The `map()` method is used to iterate over an array and apply a function to each element. It returns a new array with the modified values and is mainly used to transform or modify array data.

The `filter()` method is used to select elements from an array based on a specific condition. It returns a new array containing only the elements that match the condition.

The `forEach()` method is used to loop through each element of an array and perform an operation. It does not return a new array and is mainly used to execute a function for each element.
